# Portfolio2026

Nuovo portfolio scolastico di Giuseppe Pentrelli, progettato come capolavoro principale per l'Esame di Stato 2026-2027.

Il progetto è nella fase di analisi e sperimentazione visiva. L'applicazione completa non è ancora iniziata e le decisioni tecniche non indicate come confermate restano aperte.

L'applicazione, costruita con Vue 3, Vite, Vue Router e CSS nativo, contiene oggi lo scheletro della home (`/`) e lo Style Lab (`/style-lab`).

## Avvio locale

```bash
npm install
npm run dev
```

## Verifica della build

```bash
npm run build
```

## Regole della fase attuale

1. Una decisione alla volta.
2. Prima si definiscono obiettivi, contenuti e design; il codice viene dopo.
3. Le alternative visive si confrontano nello Style Lab prima di adottarle.
4. Accessibilità e performance sono requisiti di progetto, non rifiniture finali.
5. Nessun repository remoto, deploy o contenuto del vecchio portfolio viene modificato durante questa fase.
